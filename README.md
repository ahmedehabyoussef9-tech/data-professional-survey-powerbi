# Data Professional Survey Analysis (Power BI Dashboard)

## Overview
This project analyzes a dataset of data professionals to explore salary trends, programming preferences, job roles, and satisfaction levels. The dashboard provides insights into the data industry and highlights key factors affecting career paths.

## Tools Used
- Power BI  
- Data Modeling  
- DAX (basic measures)  
- Data Visualization  

## Dashboard Features
- Average salary by job title  
- Programming language preferences  
- Survey participants by country  
- Difficulty of entering the data field  
- Work-life balance and salary satisfaction metrics  

## Key Insights
- Data Scientists earn the highest average salaries, followed by Data Engineers and Data Architects  
- Python is the most commonly used programming language among data professionals  
- The majority of respondents are located in the United States and India  
- Many respondents report difficulty breaking into the data field  
- Work-life balance satisfaction is moderate (5.74/10), while salary satisfaction is lower (4.27/10)  
- Data Analyst roles tend to have lower average salaries compared to other data roles
